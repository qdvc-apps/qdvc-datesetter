**How PNGs are handled:**
- You can drop, open or pick PNGs from folders just like JPEG and HEIC. The app recognises them from their first bytes.
- On Set Date, a PNG gets its file **created** and **modified** dates set to the new date, in your Mac's time zone. The file is never opened for writing, so its contents don't change at all.
- Those are the only two file dates macOS lets an app set. Finder's "Date Added" and "Last Opened" are kept by macOS itself.
- PNGs get these dates **even if the "Also set each file's created and modified dates" switch is off**, since that's all a PNG has. The switch's tooltip says so.
- The confirmation counts PNGs separately, for example "2 PNG files have no EXIF dates, so their created and modified dates will be set to … instead; the files themselves aren't changed."
- PNGs show "n/a" in the three EXIF date columns. Their status after setting reads "Updated (file dates)".
